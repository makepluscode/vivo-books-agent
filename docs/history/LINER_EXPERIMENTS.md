# Liner 실험 계획 및 기록

시작일: 2026-11-17 (KST). 사용자가 해커톤 크레딧을 이용한 실험을 요청했고, BrowserOS neo로 Playground에서 진행해요.

## 목적

독자가 책의 예제를 실행하다 실패했을 때, Liner가 공식 변경 근거를 찾고 타당한 수정 후보를 제시하는지 확인해요. 이번 1차 실험은 검색·판정·수정 제안의 가능성을 확인하는 단계예요. 실제 책의 오류 재현 및 수정 코드 실행 검증과 구분해요.

## 예산·호출 범위

- 시작 잔액: Billing에서 $200.00 확인. 지급 유형 `해커톤`, 지급일 2026-11-16.
- 자동 충전·결제 수단 설정 변경 없이 진행해요.
- 첫 회차는 검색 2회, 모델 판정 4회 안팎으로 작게 시작해요. 실패한 요청은 기록하고 무작정 반복하지 않아요.
- Search는 Premium Data를 끄고 결과 5개로 시작해요.
- 모델은 Playground에서 선택된 라우터를 기록해요. 최종 제품 모델을 확정하는 실험은 아니에요.
- 종료 후 잔액과 가능한 범위의 사용량을 확인해요. 화면 반올림·집계 지연이 있으면 정확한 비용을 단정하지 않아요.

## 실험 항목

| ID | 입력 | 확인할 것 | 성공 기준 |
|---|---|---|---|
| S1 | LangChain v1 + LLMChain + 공식 문서 검색 | 변경 근거 탐색 | 공식 마이그레이션 URL과 관련 스니펫 발견 |
| S2 | 한국어로 같은 문제 검색 | 질의 언어 차이 | 같은 변경 근거를 찾는지 비교 |
| M1 | 구 import 코드·v1 환경·오류·S1 근거 | 영향 판정과 수정 후보 | classic 경로 등 근거 있는 대안 및 본문 수정 제안, 실행 검증 전 명시 |
| M2 | 현재 API를 사용한 정상 샘플 | 불필요한 수정 방지 | 근거 없이 오류로 판정하지 않기 |
| M3 | API 키 누락 오류 | 설정 문제 분리 | 버전 오류로 오인하거나 코드 교체를 권하지 않기 |
| M4 | 코드·환경·로그가 없는 '안 된다' 신고 | 불확실성 처리 | 판단 보류 및 필요한 정보 요청 |

샘플은 직접 만든 가상 코드로, 출간 원고나 내부 자료를 보내지 않아요. 모델에는 기대 정답을 전달하지 않아요. 모델 출력은 실행·자동 적용하지 않아요.

## 기록 방법

- Playground 입력·설정·출력·에러를 기록해요.
- 검색은 공식 출처 여부·관련성을 사람이 확인해요.
- 모델은 사전에 정한 성공 기준과 비교하고, 한 번의 성공을 정확도나 일반 성능으로 확대 해석하지 않아요.
- 결과를 보고 다음 단계로 실제 Python 환경의 실패→수정→성공 검증을 설계해요.

| M3 | 설정문제 판정. 키 설정 안내, 버전 변경 권고 없음 | 오류 종류 구분 적절 |
| M4 | 판단보류. 코드·버전·로그 요청 | 정보 부족 처리 적절 |

### 해석상 제한

- 가상 코드와 가상 로그를 썼어요. 실제 책의 오류를 재현한 것이 아니에요.
- M1의 핵심 수정 근거는 검색 결과만이 아니라, 이전에 공식 문서를 직접 읽어 확인한 설명도 함께 제공했어요. 따라서 모델의 독립적인 원인 발견 능력을 입증하지는 않아요.
- 검색 스니펫만으로 세부 수정에 필요한 내용이 부족할 수 있어요. 공식 원문 확인 또는 후속 검색이 필요해요.
- 검색과 모델 호출은 브라우저에서 수동으로 연결했어요. 제품 파이프라인 자동 연동은 아직 구현하지 않았어요.
- 모델이 제안한 코드를 실행하거나 원고에 자동 적용하지 않았어요.
- Playground 조작 중 BrowserOS가 `no session with given id`·30초 타임아웃을 반환해 새 탭·granular read로 복구했어요. 완료 출력이 확인된 실험만 위 표에 기록했어요. 웹 조작 타임아웃을 API 실패율로 계산하지 않아요.
- Premium Data 비활성화를 첫 탭에서 설정했으나 그 탭에 세션 오류가 생겼어요. 실제 성공 호출은 새 탭 기본 설정에서 수행했으므로 해당 옵션은 미확인으로 남겨요. 다음 실험에서는 실행 직전 요청 JSON을 저장해야 해요.

### 비용 관측

Billing 화면 시작 $200.00 → 종료 $199.99. 표시 잔액 차이는 $0.01이지만, 소수 둘째 자리 반올림과 집계 지연 가능성이 있어 정확한 호출별 비용으로 해석하지 않아요. 자동 충전이나 결제 설정은 변경하지 않았어요.
